Icons for versions whose folder holds pilots but no program to take an icon from:

| `opentie.png` | OpenTIE, `packaging/icons/opentie-icon.png` (github.com/elyosh/OpenTIE) | GPL-3.0 |
| `openxvt.png` | OpenXvT, `packaging/icons/openxvt-icon.png` (github.com/elyosh/OpenXvT) | GPL-3.0 |
| `openxwa.png` | OpenXWA, `packaging/icons/openxwa-icon.png` (github.com/elyosh/OpenXWA) | GPL-3.0 |

Scaled to 128 × 128. A version listed in `GameArtService.BuiltInIcons` without a file here falls back to the icon
found in its folder.
