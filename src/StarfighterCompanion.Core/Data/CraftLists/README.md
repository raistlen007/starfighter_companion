# Built-in craft names

Craft names by craft type for the XWA-based versions, compiled into the program (they are not read from the game).
Each line is `<craft type><TAB><name>`, taken from the version's `SHIPLIST.TXT`. Hidden (`*`) and unused
(`DontUseMe`) entries are left out and shown by number.

| File | Used for |
|---|---|
| `xwaup.txt` | XWA Upgrade 2025 |
| `xwaup2020.txt` | XWA Upgrade Mega Patch 2020 |
| `embers.txt` | Embers of the Empire |
| `tftc.txt` | TIE Fighter Total Conversion Classic and Reimagined (their names are identical) |

The original X-Wing Alliance names are in `Formats/Xwa/OriginalXwaCraftNames.cs`.
